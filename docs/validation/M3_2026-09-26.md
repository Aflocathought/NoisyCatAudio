# 0.5.0：精确频率与 MIDI 单音本机验证

日期：2026-09-26。基线提交为 `9b394d7`，在已有 0.4.1 未提交工作上继续开发；本次没有提交 Git。M3 的音频实现已接通，Bitwig 演奏、工程恢复和基础可视化仍未闭环。

## 实际交付

- `partial.rs`：周期 Hann 的复数 DTFT 模板，按 MIDI 33–93、最多 64 泛音预计算；分数频率投影、真实频率相位推进、带共轭镜像的稀疏 IFFT 合成。
- `resonator.rs`：每声道独立输入/输出 ring 和状态；一正向 FFT + 一 IFFT/hop；低、高干声与中频湿声共享窗口和分频权重。固定 N=4096、H=512。
- MIDI：最后按下优先、松键返回仍按住的音符、无键时停止新激励并保留当前尾音；力度、CC64、CC120、CC121、CC123、CLAP Note ID 与 wildcard/choke。128 个固定身份记录；满时优先回收最早释放的记录，其次最早的按键。
- 参数：Pitch Source、Harmonics、High/Low Damping、Excitation、Panic；原参数 ID 和插件 ID 保持不变。旧 `m2_wet_level` 只改显示名为 Wet Level。旧预设缺失的新参数补确定默认值，保存过的值不覆盖。
- 打包脚本先保存版本制品，新增 `-ArtifactOnly` / `-Offline`；验证脚本支持 `-PluginPath`。
- `render_m3` 示例生成左右不同的噪声打击素材、换音与自然衰减尾音，输出 IEEE float stereo WAV，并测量离线块耗时。

| 检查 | 本次结果与范围 |
| --- | --- |
| 完整频谱与直接合成 | f64、N=512，多频率偏移/相位，含 DC/Nyquist 附近；相对 RMS 小于 1e-10 |

## 有限离线性能测量

本机 AMD Ryzen 9 7945HX，Windows x86-64 release。单实例双声道，48 kHz，N=4096、H=512、128 样本块，64 泛音上限，8 秒合成素材、3000 个 callback 等效块；测量仅包括预分配 DSP 的逐样本处理，不含插件参数包装、宿主、磁盘或 UI。激活预计算本次耗时 **11.088 ms**。

| 场景 | 平均 | P50 | P99 | 最大 |
| --- | ---: | ---: | ---: | ---: |
| MIDI 33 固定、64 泛音 | 18.353 µs | 0.500 µs | 84.000 µs | 127.300 µs |
| 每 hop 在 MIDI 33–44 间换音 | 17.315 µs | 0.500 µs | 75.300 µs | 91.000 µs |

128 样本在 48 kHz 下的音频时间为 2666.667 µs。P50 很低是因为多数块没有触发 FFT，不能用它代表有 FFT 的块。单次离线测量受调度与缓存影响，不是实时宿主长时间或多实例保证。快速换音会回收过渡状态，不能把该项当作持续双声部压力测试。

试听文件位于 `target/fixtures/m3/input-stereo.wav` 和 `resonated-stereo.wav`。输出原始峰值约 0.570505，本次试听增益为 1，没有进行限幅。示例允许在峰值较大时对试听文件整体降增益，不改变插件算法。

## 实现限制与 Bitwig 待办

1. 0.5.0 已更新磁盘上的稳定插件文件；正在运行的宿主是否重载新 DLL 未验证。重启/重新扫描后确认版本，在新建立体声实例中检查左右不同素材。
2. MIDI 基音范围为 33–93，越界忽略，不钳到边界。每 hop 最终选择一个音符，短 Gate 只影响平均激励；长窗仍可能包含音符开始前的音频。hop 控制量化最大 511 样本，不能等同于整个声音变化只延迟 511 样本。
3. 换音使用两套状态约 20 ms 过渡后再 OLA；快速密集换音会回收正在淡出的状态。Choke 和 Panic 不会撤回已经排进输出 ring 的音频。宿主需试听瞬态与杂音，不宣称样本级 MIDI Gate。
4. 目前只测量上述频率、采样率、偏移和 T60 条件；完整音符/采样率/参数扫频、边界相消重组、长期满负载以及多实例仍待扩大。无隐式输出限幅，高增益会超过 0 dBFS。
5. Bitwig 验收：Internal 有音频的共鸣；MIDI 无键/有键/无音频；重复音、松键回退、踏板、Panic；保存关闭重开；自动化；不同缓冲和采样率；多实例 CPU。CLAP 状态验证不替代真实工程恢复。
6. 仍使用宿主参数面板；基础频谱/电平显示、M4 复音、M5 GPU 编辑器、VST3、正式状态 schema 与发行许可审查未完成。未来版本状态拒绝不是本次默认值补齐能够实现的能力。
