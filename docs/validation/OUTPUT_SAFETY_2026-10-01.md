# 输出保护检查：2026-10-01

对象：当前工作树的 Specatral Resonator 0.15.0 源码。结论：**没有最终峰值限幅器、真峰值限制或响度归一化；主输出和辅助湿声输出都可能超过 0 dBFS。** 本次仅检查，没有改变 DSP、增加削波或改变延迟。

## 代码证据

- 插件在 `src/lib.rs` 的 `Plugin::process` 中先按路由组合干湿声，再对主输出调用 `spectral_dsp::apply_frame_gain`。辅助 Wet 输出直接写入 `wet[i] * gain`。
- `crates/spectral-dsp/src/lib.rs` 的 `apply_frame_gain` 仅执行乘法，没有峰值钳制或非有限数值替换。
- `Output Gain` 的线性范围为 0–2，`Wet Level` 为 0–16；激励、复音叠加、音头强调等还会改变电平。限制参数范围并不保证最终音频峰值范围。
- 引擎对输入及部分频域状态有 `is_finite` 检查，高频衰减用于频率边界保护。这些不是最终输出限幅，也不是覆盖整条链路的 NaN/Inf 防护。

## 离线数值探针

探针调用当前源码中的真实 DSP 引擎与最终增益函数；在稳定路由下按插件当前公式分别计算 Mixed、Wet only、Dry contribution 和辅助 Wet 输出。它没有加载发布版 CLAP、没有连接声卡，也没有测量扬声器声压。全部输出只在内存中统计。

共同条件：48 kHz、2 声道、FFT 4096、hop 512、1 秒 440 Hz 正弦；左声道输入峰值 0.9，右声道为左声道的 −0.5 倍；64 泛音、默认衰减/阻尼、Spectral 模式、Unison 单路、Output Gain=2。湿声场景使用 Wet Level=16、Mid Mix=100%；干声场景 Mid Mix=0、Wet Level=0。16 声部场景使用不同音符身份触发同一个 MIDI 69 音符，属于可接受的重复同音输入。

| 场景 | Mixed 采样峰值 | 相对 0 dBFS | Wet / 辅助 Wet 采样峰值 |
| --- | ---: | ---: | ---: |
| 干声路径 | 1.8000001 | +5.11 dBFS | 0 |
| 单声部、高湿声增益 | 26.753717 | +28.55 dBFS | 26.695124 |
| 16 个同音声部、高湿声增益 | 427.18054 | +52.61 dBFS | 427.12198 |

这三组统计未发现非有限输出，但不覆盖全部输入、参数、自动化、采样率或宿主。它们不是理论最大值，也不能解释为实际播放声压。以绝对采样幅度 1.0 为 0 dBFS，使用 `20*log10(peak)` 换算；没有做过采样真峰值或 LUFS 测量。浮点宿主可以在内部保留超过 0 dBFS 的信号，但后续处理、导出或设备输出仍可能削波或异常。

独立增益函数检查中，`[0.75, -0.5] × 2` 得到 `[1.5, -1.0]`。向该函数人工输入 NaN/Inf 后仍为非有限值，说明它没有末端异常值替换；此项不表示上述正常信号测试产生了 NaN/Inf。
