# 0.10.1 瀑布方向与固定布局

日期：2026-09-27。本轮只调整 UI 映射、控件布局和版本标识，音频 DSP、参数值、分析窗与帧率调度沿用 0.10.0。

## 改动

- 瀑布图改为底部出现新数据，历史向上移动、从顶部消失。复用原环形 GPU 纹理，只调整两段 UV 的方向和位置，不复制整幅历史。NOW 标识移到下方，−1/−2/−3/−4 秒刻度从下向上排列；调试 FPS 开启时省略会与其重叠的最顶部时间文字，保留网格线。
- 旋钮行高由 60 减为 44 逻辑像素，旋钮直径和操作区域保持原大小，文字顶部对齐可见圆形上缘，名称与数值间距收紧。
- 所有页统一预留 380 像素底部高度，参数区不再随内容自动收缩；同一窗口尺寸下切换页签，频谱、常用控件和页脚固定不动。
- 下面采用统一三列等宽网格，衰减图跨两列，参数占第三列；下拉选择器与所在列同宽。窗口增加的高度仍全部留给频谱。

## 已验证

- 8 项编辑器相关测试通过（含实际 GPU 离屏渲染），日志 `target/ui-0.10.1/ui-tests.log`。布局覆盖 980×700、1120×780、1120×1100，增加同尺寸四页频谱区域完全一致的断言；加高 320 像素时频谱仍增加 320 像素。
- 原有五位显示/精确输入、整数旋钮慢拖动、隐藏参数保留、曲线与分频手势、设置持久化检查通过。
- GPU：NVIDIA GeForce RTX 4060 Laptop GPU / Vulkan / 595.97。检查 `target/ui-preview/` 中的 Resonance、Curve、Motion、Routing、Settings 和加高窗口预览，确认瀑布方向、文字对齐、曲线空间和 FPS 标签避让。这是自有测试渲染，不是音频宿主截图。
- 格式化、全目标/全功能 Clippy `-D warnings` 通过。没有改动音频路径，因此未重复全部 DSP 和 Bounce 音频对比；上一版音频回归见 [0.10.0 记录](UI_CONTROLS_2026-09-27.md)。

- 最终制品 CLAP validator：36 passed、0 failed、0 warnings、8 skipped，日志 `target/ui-0.10.1/validator.log`。
- 实际插件窗口在 60 FPS 档完成三次创建、缩放、隐藏、关闭重开，尺寸 1120×780 → 1260×860 → 980×700，独立音频线程处理 2418 块。日志 `target/ui-0.10.1/lifecycle.log`。本轮没有重做四档性能基准，0.10.0 的实测结果不能当作本版重测。
