# 0.11.0 独立 Attack 与 5 ms Decay

日期：2026-09-27。针对用户描述的音头渐进感，新增可选择的上升响应，并缩短共鸣状态的最小衰减时间。尚未直接测量用户的 Bitwig 工程；下面的结论来自源码、确定性音频渲染和测试宿主。

## 使用方式与兼容性

Resonance 页 `Attack response` 默认为 `Natural`，保留原来的响应方式。选择 `Independent` 后显示 `Attack / 90%`，范围 0–2000 ms，初始值 10 ms。可先试 0–10 ms；切回 Natural 不会重置隐藏值。Bitwig 参数面板的 Envelope 远程页也提供这两个控制。

全局 Decay / T60、六个曲线节点以及 Damping 计算结果现在都允许 0.005–12 秒。短尾音可先试 0.02–0.1 秒；Curve 模式应改节点秒数。图形坐标与 DSP 共用相同上下限，保持五位有效数字显示和更精确的输入。

旧预设缺失 `attack_mode` 时补 Natural，缺失 `attack_ms` 时补 10 ms，已有值不覆盖。此次扩大 Decay 范围会改变其标准化位置；保存的物理秒数保持不变，但跨版本的宿主标准化自动化不能保证相同轨迹。旧预设中被 50 ms 下限截住的强 Damping 泛音，现在可能继续缩短至 5 ms。这是范围放宽的音色变化，不是参数重置。建议保留旧版制品用于比较。

## 原因与算法

原来每个泛音的复数状态为 `z_next = r_d * R * z + (1-r_d) * u`，其中 `r_d = 10^(-3*hop/(rate*T60))`，`R` 是相位旋转，`u` 是带速度和激励增益的频谱投影。对同频持续激励，上升和下降共用同一个极点；T60=2 秒时，理想状态从零到 90% 约需 667 ms，此外还有分析与合成窗口的影响。

Independent 在 `|u|² > |z|²` 时使用上升极点 `r_a = 10^(-hop*1000/(rate*attack_ms))`，0 ms 时取零；下降、无输入及松键仍使用衰减极点。输入和反馈始终使用同一个所选系数，形成有界加权和，避免单纯放大激励造成持续音增益随 Decay 增长。比较在每个声部、泛音和声道独立进行，因此同一 MIDI 音符内重复的音频瞬态也有效。无需新的 FFT、声部或数组分配。

模式系数约 20 ms 过渡；回到 Natural 的过渡保留上一次 Attack 极点，不清空状态。原有声部淡入、抢占/Panic 淡出、Pan 平滑和 4096 samples 延迟保持原设计。完整曲线模式直接读取曲线极点，避免 5 ms 极小系数与大系数相减时的浮点消减误差。

Independent 是非线性包络响应整形：快速起音会改变频率选择性、瞬态电平及音色，不能理解为原共鸣器的完全等音色加速。安静尾音上的更小新瞬态仍可能受已有共鸣状态影响。它也不替代 Granular 的颗粒包络或 Post Unison 的可变延迟。

## 音频测量

48 kHz、单个 440 Hz 泛音、无 Damping/调制、Wet=1、T60=2 秒。对从静音开始的持续正弦，按 10 ms RMS 窗、1 ms 步长寻找达到目标稳态响度 90% 的位置。下表从输入起点计时，**包含处理延迟，没有减去 4096 样本**。

| 响应 | 到达 90% |
| --- | ---: |
| Natural | 723 ms |
| Independent / 0 ms | 110 ms |
| Independent / 10 ms | 112 ms |
| Independent / 400 ms | 465 ms |

44.1/48/96 kHz 的测试均覆盖同一音符内两次音头、Internal 与 MIDI 路径，快 Attack 的第一次结果分别约为 122/112/56 ms。输入停止且窗口排空后，三个响应模式的尾音都符合 T60=2 秒的一秒下降 30 dB，误差低于 2%。Damping 和 Curve 的 5 ms 衰减状态另有跨采样率测试，松键后每 hop 的衰减比符合目标，误差低于 0.5%。

30 ms 正弦脉冲在 Natural/2 秒时湿声峰值约 0.01971，Independent/10 ms 时约 0.12005；输入均为 0.2，没有逐文件归一化。快速 Attack 确实会抬高原本被渐进过程压低的短音头，试听时可配合 Wet Level。N=4096/H=512 的时间展宽依然存在：在 48 kHz 下分别约 85.3/10.7 ms，5 ms T60 不等于最终只输出 5 ms。

可复现的示例：

```powershell
cargo run -p spectral-dsp --release --example render_envelope --locked --offline
```

输出到 `target/envelope-0.11.0/audio/`，包含输入、各响应的持续音/重复音头 WAV 和 `measurements.csv`。这些是 DSP 离线音频，不是 Bitwig 录制。

- 模拟 Bounce 三组配置：Natural/50 ms、Independent Attack 10 ms/Decay 5 ms、Independent Attack 0 ms/Curve 5 ms。每组覆盖 Internal/MIDI × Spectral/Post × 48/44.1/96 kHz，共 36 个离线配置；参数保存恢复、停止、重启和尾音排空均通过。日志位于 `target/envelope-0.11.0/bounce-*`。
