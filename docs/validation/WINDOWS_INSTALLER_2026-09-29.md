## 行为

中英文向导支持当前用户／所有用户安装，首次可浏览选择 CLAP 目录。默认分别为 `%LOCALAPPDATA%\Programs\Common\CLAP` 和 `%COMMONPROGRAMFILES%\CLAP`，遵循 CLAP 官方搜索约定。支持文件和卸载器放在独立 AflocatAudio 产品目录，不污染共享 CLAP 目录。

固定产品 AppId `AflocatAudio.SpectralResonator.CLAP`，固定插件文件名与原 CLAP ID。版本和目录保存在本产品注册项；更新沿用目录，同版本可修复，较低版本被拒绝。迁移目录或切换安装范围需要先卸载，以免安装器制造两份同 ID 插件。无法自动发现任意目录中的手动副本；首次覆盖同目录手动文件会确认纳入安装器管理，静默模式拒绝。

安装与卸载均检查插件是否可独占写入。检测到 DLL 占用时停止，提示用户关闭宿主后重试；没有自动关闭应用、删除扫描目录或重启替换插件的操作。卸载依据精确文件记录，只移除本产品文件／注册项，不删除品牌共享设置。运行库由微软安装器独立管理，插件卸载不会移除它。

PE 导入表确认依赖 `VCRUNTIME140.dll` 原始 2015 ABI（包括 `__CxxFrameHandler3` 等）和 Windows 自带 UCRT。安装包内嵌官方 x64 VC++ 运行库，只有兼容运行库缺失才启动其安装；取消／失败先于插件复制。若运行库要求重启，显示重启后重试，不继续半安装。本机检测到系统运行库 14.51.36247.0，正确跳过包内较旧组件。

## 已执行的检查

`scripts/test-windows-installer.ps1` 的最终安装逻辑回归通过 **32 项断言**，记录在：

`target/installer-tests/223f82da9b4242cf842fe1ee5899de3d/results.json`

测试使用随机独立 AppId／注册项，并在编译时限制插件和支持目录都必须位于本次 `target/installer-tests/<id>`，不接触正式安装或音频宿主。

- 使用真实且不同的 0.14.1／0.15.0 CLAP，安装到含中文和空格的自定义目录；安装字节哈希、版本记录和 Windows Installed Apps 入口正确。
- 将已安装的原生 DLL 加载到测试进程，更新和卸载都返回非零退出码，旧文件哈希和安装记录保持不变。释放 DLL 后可升级成功。
- 升级不传目录时准确沿用原目录；传入不同目录被拒绝，不产生另一份插件。同版本修复成功，降级拒绝且新文件保持不变。
- 卸载后插件文件和本产品两个注册项消失，同目录第三方哨兵插件保持原哈希；真实 `com.aflocat.audio/settings.json` 内容保持不变。再次安装、再次卸载均成功。
- 静默安装面对未登记的同名插件文件时拒绝覆盖；模拟缺失运行库时在插件复制之前停止，测试包禁止修改系统运行库。

第一次受限沙箱运行由于 HKCU 注册表写入权限不足而中止，Inno 执行回滚并移除了已复制的本产品文件。随后测试在具备测试 HKCU 写入权限的环境完成。另修正了初版测试 AppId 超长造成的 Inno 注册项名缩短问题；生产 AppId 长度没有该问题。

`scripts/probe-windows-installer.py` 对隔离产品执行真实向导导航、安装和卸载，直接捕获其自身窗口。已查看目录页、安装摘要和完成页；修正了完成提示不能通过 `[Messages]` 展开 `{cm:...}` 的问题，并使长目录在摘要中换行。最终截图和控件文本在同一测试目录的 `wizard-preview/`。完成页正确提醒宿主重扫、自定义目录和旧手动副本。最后仅调整摘要换行后，重新构建发布包并复测该 UI 流程；安装逻辑未再修改。

PowerShell 脚本语法检查、Python 语法检查和 `git diff --check` 通过。工具准备脚本在已有固定下载文件的情况下运行通过，并核验两个下载的哈希／签名。

## 证据边界

已测试当前用户模式；未自动执行所有用户模式的 UAC 安装、干净 Windows 上的 VC++ 安装／重启流程，也未测试其他用户账户、ARM64 模拟环境或所有显示 DPI。测试包对缺失运行库只验证前置阻断，不执行系统组件安装。没有实际加载用户音频宿主工程，也没有宣称真实扫描、试听或 Bounce 问题因此解决。

生产包和测试包来自同一安装器源码；测试包使用独立身份、受限路径及系统运行库禁止安装分支。生产 AppId 的实际安装／卸载尚未在用户机器执行。
