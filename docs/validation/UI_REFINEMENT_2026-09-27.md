# 0.9.1 瀑布图速度、低频精度与缩放

日期：2026-09-27。只修改显示分析与 UI，不修改音频 DSP、宿主参数或已有路由。

## 行为

- GPU 环形纹理由 512×256 改为 512×128，仍约 30 行/秒；连续音频的历史长度由 8.53 秒缩为 4.27 秒，相同图高下滚动快一倍。每秒刻度帮助判断时间。更新频率不翻倍。
- 400 Hz 以下使用 16384 点 Hann 窗，400–1000 Hz 按对数频率混合长、短窗功率，1 kHz 以上保留 4096 点窗。左右声道分别 FFT，再按功率平均。长短窗都以同一个最新音频样本为终点，因此低频有较宽的时间轮廓。
- 48 kHz 下，低频 FFT 频点间隔从 11.71875 Hz 变为 2.9296875 Hz；长窗 341.33 ms，短窗 85.33 ms。频点间隔不等于任意两音的可分辨距离，Hann 主瓣和信号条件也有影响。44.1/96 kHz 下长窗间隔分别约 2.69/5.86 Hz。
- 开窗、恢复或丢包后，先等短窗填满即可显示；长窗连续数据填满前使用短窗结果，不混入断点前的旧音频。长窗通常在约 341 ms 后接入低频（48 kHz，另加不超过一行的调度间隔）。
- 小于一个 FFT bin 宽的频率像素改为中心插值，较宽像素取其实际覆盖 bin 的峰值，减少低频被邻近 bin 反复涂宽。投影和混合权重只在采样率变化时重新计算。
- 底部参数与说明保留固定逻辑高度；瀑布图取消 380 像素上限，窗口每增加 1 像素高度，频谱增加 1 像素。最小窗口仍为 980×700。

显示 FFT 全部位于 UI 线程，有额外 CPU 成本。音频侧依然使用 256 帧数据包、有界队列且饱和即丢显示数据；保持 4096 样本干声补偿，不增加音频延迟。时间刻度表示连续采样历史，暂停、丢包和音频重置由断点行表示，不是墙上时钟记录器。
