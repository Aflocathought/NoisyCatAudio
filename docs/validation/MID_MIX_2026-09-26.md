# 0.5.1：中频 Mid Mix

日期：2026-09-26。在 0.5.0 基础上增加用户要求的中频干湿比例，保留已有精确音高、MIDI、立体声和延迟；尚未进行本版本的 Bitwig 试听。本次未提交 Git。

## 参数与路由

宿主显示 `Mid Mix`，稳定 ID 为 `mid_mix`，百分比范围 0–100、默认 100，20 ms 线性平滑。DSP 在 hop 边界使用平滑值。旧预设缺失该参数时补为 100；已保存的比例保持原值。

令 q 为归一化比例、M 为原中频权重、g 为 Wet Level，则同一 Hann 窗频谱中的输出为：

```text
Y[k] = (1 - q*M[k])*Dry[k] + q*M[k]*g*Wet[k]
```

- 0%：中频也使用干声，整体恢复延迟 4096 样本的全频干声，之后仍经过 Output Gain。
- 50%：中频干声和经过 Wet Level 的共鸣湿声各占一半。
- 100%：保持 0.5.0 的中频共鸣路由。

低、高频干声路由保留；Mix 不等同于 Wet Level。线性混合没有额外的等功率增益。共鸣状态在 Mix=0 时继续演算，重新调高不会重置尾音；不新增缓冲、FFT 或延迟。

## 本机验证

Rust/Cargo 1.92.0、nice-plug 0.4.2、RustFFT 6.4.1、clap-validator 0.4.1。本次未新增依赖。

- **26 项源码测试全部通过**，包括此前 24 项回归测试；格式检查、Clippy `--workspace --all-targets --locked --offline -- -D warnings` 和 release 构建通过。
- 新增 DSP 检查覆盖 44.1/48/96 kHz、三组分频点、双声道不同输入及脉冲：0% 与延迟干声的最大绝对误差为 `8.940697e-8`；50% 与两个端点算术平均的最大误差为 `1.1920929e-7`。100% 仍通过原来的音准、T60、分频与声道隔离检查。
- 验证 Mix=0 与 Mix=100 时共鸣内部状态完全一致，确认比例控制不会清空或停止尾音。
- 新增实际 `Plugin::process` 回调检查：MIDI 正在激励时，Mix=0 输出仍恢复延迟干声，静音右路保持零；回调中的分配、重分配和释放计数均为 0。
- 旧状态缺省 Mix=100 和已有 Mix=35 的恢复检查通过。
- 独立制品与更新后的稳定路径分别通过 CLAP 验证：各 **36 通过、0 失败、0 警告、8 跳过**。Bitwig 重新扫描、旋钮试听及工程内自动化/恢复仍需宿主验收。
