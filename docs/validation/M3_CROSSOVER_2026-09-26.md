# 三频段 crossover 原型：0.4.0 本机验证记录

日期：2026-09-26。基线提交 `9b394d7` 是 M2 原型；本记录对应其后的工作区更改，尚未提交。它只完成 M3 的分频组件，**不代表 M3 精确音高或 MIDI 已完成**。

## 实现范围

- CLAP 版本 0.4.0；2→2 声道布局列在第一位，1→1 仍可选。nice-plug 将首个布局作为默认布局。用户反馈 0.3.0 在左右不同的立体声输入下仍听起来像单声道，因此 0.4.0 改默认协商顺序；实际音频宿主端口配置仍待复验。
- `Low / Mid` 默认 250 Hz，`Mid / High` 默认 4 kHz。在每个声道的同一 FFT 帧里，低、高频取输入频谱，中频取整数 bin 共鸣状态。两边界使用六次幂权重，带外渐近目标为约 36 dB/oct；干声权重始终为 `1-M[k]`。
- `M2 Wet Level` 是湿声增益，不是逐段 Mix。根据用户的响度反馈，全新实例默认值从 1 提高到 4，上限从 4 提高到 16；旧工程保存的值可能继续为 1。输出可能超过 0 dBFS，需用 Output Gain 和宿主电平表检查。Wet Level 为 0 会静音中频，不是全频旁路。
- 当前共鸣仍吸附到整数 FFT bin。双声道使用独立共鸣状态和音频 ring，只共享只读分频权重；没有主动立体声拓宽、Detune 或 Wander。

## 已运行的检查

- `cargo fmt --all`、`cargo test --workspace --locked --offline`、`cargo clippy --workspace --all-targets --locked --offline -- -D warnings` 通过。9 项源码测试通过、0 失败；新增检查覆盖默认双声道布局、100 Hz 与 10 kHz 干声保留、1 kHz 中频干声抑制、左右声道不串音，以及分频权重范围与带外斜率。
- release DLL 编译通过。音频宿主当时占用稳定 `.clap` 文件，打包脚本无法覆盖；将 DLL 复制到 `target/artifacts/0.4.0/my_spectral_resonator.clap` 后运行 clap-validator，44 项中 33 通过、0 失败、0 警告、11 跳过。用户关闭音频宿主后，已将同一制品复制到 `target/bundled/my_spectral_resonator.clap`，两份 SHA-256 均为 `CB9A22BF25A7541BC7F64507E289FDE703313DD88500655E91E209C3203F5C00`；对稳定路径再次运行验证器，同样通过。
- 插件仍报告 4096 样本延迟。当前分频在原有 STFT/IFFT 中完成，不增加第二条固定延迟路径。参数目标逐样本平滑，权重在 hop 边界更新，音频生效最多量化一个 hop。

## 尚未验证

0.4.0 尚未在音频宿主确认实际 2→2 协商、左右不同素材的输出、响度与削波、分频点自动化、工程恢复或 CPU 高分位耗时。离线测试证明代码路径相互独立，不能替代宿主端口配置的观察。频点权重的渐近斜率也不等于整套 STFT 对实际素材的精确幅频曲线；仍需扫频和听感检查。
