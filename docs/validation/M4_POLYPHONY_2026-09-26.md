# 0.6.0：MIDI 复音与自然尾音

日期：2026-09-26。基于已有 0.5.1，针对“只能单音，换音像清空上一共振器”的反馈实现固定 8 声部。此前两套单音状态会在换音时短淡出旧音，无法保留多个独立持续共振。此次保留原有 Mid Mix、分频、阻尼、默认双声道和固定报告延迟。本次未提交 Git，保留工作区已有修改。

## 行为与实现边界

- MIDI note-on 为每个音符建立独立身份、Gate、力度、左右复数共鸣状态；普通 note-off 只关闭该音符的新激励，尾音继续按 Decay T60 衰减。新音符不会重置或缩放其他声部，重复同音也可重叠。
- 8 声部包含释放尾音；已释放且状态能量低于 `1e-16` 时回收，按住的静音声部保留。每个声部最多 64 泛音，各声道共享 FFT/IFFT，不为每个声部重新计算 FFT。
- 池满时优先抢占能量最低的释放声部，否则最早按下的声部。旧声部约 20 ms 淡出后启动替代音符；按 H=512 量化，在 48 kHz 下满增益声部经过两个 hop、最长约 21.33 ms 完成淡出。这段额外启动等待只发生于声部抢占，之后还有新音符淡入及 STFT 窗口的时间混合。
- 每槽只有一个待启动音符。所有槽都在淡出时，新事件替换最早的待启动音符，保持正在播放的淡出进度。待启动音符响应 Release/Choke；短音符已累计的 Gate 不丢失，但首次注入不超过一个完整 hop，避免等待引起增益突增。这是固定容量超额策略，不承诺超过 8 声部时保留所有音符。
- 保留 CC64、CC120、CC121、CC123、CLAP 通配符/Choke；音符事件按宿主样本偏移接收，各声部独立累计 hop 内 Gate。模式切换和 Panic 淡出全部湿声，保留干声历史；MIDI 记录重置不重复使用旧 token。宿主 reset 清空全部音频历史。
- 各声部直接相加、干声只混入一次，不随声部数量自动降低旧尾音。单音电平不变，和弦峰值可能上升，可通过 Wet Level / Output Gain 留出余量；没有隐藏限幅器。
- 固定 N=4096、H=512，报告延迟仍为 4096 样本。参数 ID、保存格式及 Mid Mix 旧状态补默认规则不变。内部 Root Note 切换也使用同一声部池保留自然尾音。

“平滑换音”指自然尾音重叠和新声部淡入，满额时受控淡出抢占；尚无连续滑音、Pitch Bend、MPE 或逐声部参数调制。音符范围仍为 MIDI 33–93，必须有音频输入作为激励。无自定义编辑器、频谱显示或 VST3。

## 源码与制品验证

本机 Rust/Cargo 1.92.0、nice-plug 0.4.2、RustFFT 6.4.1、clap-validator 0.4.1，未新增依赖。

通过的命令：

```powershell
$env:CARGO_HOME = Join-Path (Get-Location) 'target/cargo-home'
$env:RUSTUP_TOOLCHAIN = '1.92.0'
cargo fmt --all -- --check
cargo test --workspace --locked --offline -- --nocapture
cargo clippy --workspace --all-targets --locked --offline -- -D warnings
cargo run -p spectral-dsp --example render_m4 --release --locked --offline
./scripts/bundle-clap.ps1 -ArtifactOnly -Offline
./scripts/validate-clap.ps1 -PluginPath target/artifacts/0.6.0/my_spectral_resonator.clap
# 核验版本副本后更新稳定路径，再验证稳定文件。
./scripts/validate-clap.ps1
```

**36 项源码测试全部通过：DSP 18 项，插件 18 项。** 新增及加强的行为证据包括：

- 两个音符交叠、先后松键后，DSP 和实际 `Plugin::process` 的和弦输出都等于独立音符输出之和减去重复干声，误差低于 `3e-6`；两个已释放音符的尾音均有可测能量。
- 新音符加入时旧声部复数状态不变；下一个 hop 旧状态恰好按自身目标频率旋转和 T60 半径衰减，增益仍为 1，没有被换音淡出。
- 同一 hop 内两个短音符和重复同音保留独立状态、力度；Choke 只淡出指定身份的尾音。
- 覆盖最安静释放声部/最早按住声部的抢占，待启动音符的松键与 Choke，以及所有声部已在淡出时的密集事件，确认不会立即重写可听状态或重新开始淡出。
- 插件持续踏板释放与把 note-off 延后到踏板释放时刻的音频逐样本一致。覆盖 channel、voice ID、通配符、零力度、ID 重用和重置后的 token 唯一性。
- 在实际回调中加入密集抢占及短 note-off；固定 128 点块与混合 `1/7/64/127/257/512/1024` 块得到逐样本相同输出，静音右路保持零。回调内堆分配、重分配、释放计数均为 **0**。
- 原来的音准、T60、分频、Mid Mix、状态默认值与立体声测试继续通过。44.1/48/96 kHz 的原音准测试最坏误差约 `0.002404` 音分，T60 比例相对误差约 `0.000100`；新复音音频比较主要在 48 kHz 进行。

版本副本和更新后的稳定文件各自通过 CLAP 验证：**36 通过、0 失败、0 警告、8 跳过**。格式检查、Clippy 全目标检查和 release 构建通过。

## 离线性能与试听素材

本机 CPU：AMD Ryzen 9 7945HX with Radeon Graphics。Windows x86-64，release，48 kHz、立体声、N=4096、H=512、块长 128，每声部 64 泛音、T60=2 秒。每种场景处理 8 秒合成素材，共 3000 块；输入前 5 秒为左右不同的衰减噪声，之后静音。计时包含逐样本 DSP 和事件分派，不包含初始化、输入生成、文件写入与耗时数组扩容；FFT 工作集中在每四个块中的一个。

| 场景 | mean µs | p50 µs | p99 µs | max µs |
| --- | ---: | ---: | ---: | ---: |
| 8 个低音持续按住（MIDI 33–40） | 47.930 | 1.100 | 192.700 | 240.700 |
| 每 0.25 秒替换整个 8 音和弦 | 40.571 | 1.100 | 191.900 | 204.800 |
| 每 64 样本加入新音，持续触发抢占 | 40.631 | 1.100 | 192.200 | 223.600 |

每块音频时间为 `2666.667 µs`。本次最坏 p99 约占 7.23%，最大块耗时约占 9.03%。这是短时离线引擎测量，未覆盖 Bitwig 线程调度、声卡、其他插件、电源模式变化或 10 分钟实时播放；不能据此保证宿主没有 underrun。

`render_m4` 还生成两组四音和弦交替、旧和弦自然释放的 8 秒音频：

```text

target/fixtures/m4/polyphonic-stereo.wav
```

输出峰值 `0.577116`，试听文件增益 `1.0`。两组和弦分别在第 0、2 秒启动，前组在第 2 秒松开，后组在第 4 秒松开；音频输入在第 5 秒停止。输出文件是合成测试素材，尚未进行主观试听验收。
