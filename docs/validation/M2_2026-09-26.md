日期：2026-09-26。项目 Git 仓库尚无首次提交，因此以源码、`Cargo.lock` 和下列命令作为当前重现依据。

## 构建与行为边界

| 项目 | 本次值 |
| --- | --- |
| 平台与工具链 | Windows x86-64 MSVC；插件 Rust/Cargo 1.92.0 |
| 插件版本与标识 | 0.3.0；CLAP ID `org.spectral-resonator.dev` 保持不变 |
| 固定 STFT | N=4096、H=512；支持 1→1 与 2→2；报告 4096 样本延迟 |
| 共鸣控制 | `Root Note` 默认 MIDI 57；`Decay T60` 默认 2 s；`M2 Wet Level` 默认 1，范围 0–4 |
| 输出 | 延迟干声加整数 bin 共鸣湿声，再经原有 Output Gain；`M2 Wet Level=0` 时只有延迟干声 |

每个声道独立保存正频率复数状态，使用半径 `10^(-3H/(fs·T60))` 和 `2πkH/N` 相位推进。当前最多激励 32 个吸附到最近 bin 的泛音；更换 Root Note 后旧 bin 的状态继续衰减。`M2 Wet Level` 是原型参数，**不是**计划中的低／中／高 crossover 或最终干湿设计。
